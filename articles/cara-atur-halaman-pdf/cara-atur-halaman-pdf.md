# Cara Mengurutkan, Memutar, dan Menghapus Halaman PDF

PDF hasil scan sering berantakan: ada halaman terbalik, urutan tertukar, atau halaman kosong ikut terpindai. Semua itu bisa dirapikan tanpa scan ulang.

## Memutar Halaman

Halaman diputar per 90 derajat. Rotasi disimpan di pengaturan halaman PDF (atribut /Rotate), jadi isi halaman tidak dikompres ulang dan kualitasnya tetap sama.

## Mengubah Urutan

Geser thumbnail halaman ke posisi yang benar. Cara ini lebih mudah daripada mengetik nomor halaman, terutama untuk dokumen hasil scan bolak-balik yang urutannya acak.

## Menghapus Halaman

Pilih halaman kosong atau yang tidak diperlukan, lalu hapus. File asli tidak berubah, hasilnya disimpan sebagai file baru.

## Langkah

1. Buka [atur halaman PDF](https://tools.muzanella.com/atur-halaman-pdf) dan pilih file.
2. Putar, geser, atau hapus halaman lewat thumbnail.
3. Unduh hasilnya.

File diproses di browser Anda dan tidak diunggah.

## Tips untuk Dokumen Scan

- Setelah dirapikan, file scan biasanya masih besar. Kecilkan dengan [cara mengompres PDF hasil scan](../cara-kompres-pdf/cara-kompres-pdf.md).
- Kalau hanya butuh beberapa halaman, [pisah PDF](../cara-pisah-pdf/cara-pisah-pdf.md) lebih cepat.
