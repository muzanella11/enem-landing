# Token Listrik 100 Ribu Dapat Berapa kWh? Ini Hitungan per Golongan

Token Rp100.000 tidak berarti Rp100.000 penuh menjadi listrik. Biaya admin diambil lebih dulu, lalu ada pajak daerah (pajak penerangan jalan), baru sisanya dibagi tarif per kWh.

## Rumus

kWh = (nominal - admin) / (1 + pajak daerah) / tarif per kWh

Pajak daerah atas tenaga listrik berbeda per daerah. Contoh di bawah memakai 3% dan tanpa biaya admin.

## Tabel Token Rp100.000

Tarif Triwulan IV 2026 (Oktober sampai Desember):

| Golongan | Tarif per kWh | kWh dari Rp100.000 |
|---|---|---|
| R-1 450 VA (subsidi) | Rp415 | 233,9 |
| R-1 900 VA (subsidi) | Rp605 | 160,5 |
| R-1 900 VA RTM | Rp1.352 | 71,8 |
| R-1 1.300 VA dan 2.200 VA | Rp1.444,70 | 67,2 |
| R-2 3.500 sampai 5.500 VA | Rp1.699,53 | 57,1 |

Contoh 1.300 VA: Rp100.000 / 1,03 = Rp97.087 untuk listrik, Rp2.913 untuk pajak daerah. Rp97.087 / Rp1.444,70 = **67,2 kWh**.

Golongan R-3 (6.600 VA ke atas) juga dikenai PPN 11%, jadi kWh yang didapat lebih sedikit dari R-2 walaupun tarifnya sama.

## Pengaruh Biaya Admin

Biaya admin tergantung tempat membeli (bank, e-wallet, minimarket). Untuk 900 VA subsidi tanpa pajak daerah, token Rp50.000 memberi 82,6 kWh. Dengan admin Rp2.500, hasilnya turun ke 78,5 kWh.

## Memperkirakan Pemakaian

kWh sebulan = watt x jam pemakaian per hari x jumlah alat x 30 / 1.000. AC 350 watt yang menyala 8 jam sehari memakai sekitar 84 kWh sebulan.
