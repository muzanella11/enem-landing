# Cara Memisahkan Halaman PDF dan Mengambil Halaman Tertentu

Kadang yang dibutuhkan hanya sebagian halaman: halaman pengesahan dari skripsi, satu halaman dari rekening koran, atau lembar tertentu dari kontrak. Memisahkan PDF berarti menyalin halaman yang dipilih ke file baru, tanpa mengubah file aslinya.

## Menulis Rentang Halaman

- `1-3` berarti halaman 1, 2, dan 3.
- `5` berarti halaman 5 saja.
- `1-3, 5, 8-10` menggabungkan beberapa pilihan sekaligus.

Nomor halaman yang dimaksud adalah urutan halaman di file PDF, bukan nomor yang tercetak di kaki halaman. Skripsi dengan halaman romawi di bagian awal sering membuat keduanya berbeda.

## Langkah

1. Buka [pisah PDF](https://tools.muzanella.com/pisah-pdf) dan pilih file.
2. Tulis rentang halaman yang ingin diambil.
3. Unduh file barunya.

File diproses di browser Anda dan tidak diunggah ke server, sehingga aman untuk dokumen berisi data pribadi.

## Kapan Memakai Alat Lain

- Kalau ingin menghapus beberapa halaman sambil melihat thumbnail-nya, atau memutar halaman yang miring, lebih praktis memakai [atur halaman PDF](../cara-atur-halaman-pdf/cara-atur-halaman-pdf.md).
- Kalau ingin menyatukan beberapa file, lihat [cara menggabungkan PDF](../cara-gabung-pdf/cara-gabung-pdf.md).
