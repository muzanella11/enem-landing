# Cara Mengubah HEIC, PNG, dan WebP ke JPG

iPhone menyimpan foto dalam format HEIC secara bawaan. Format ini efisien, tetapi banyak formulir online dan aplikasi di Windows belum menerimanya. Solusinya adalah mengubahnya ke JPG.

## Langkah

1. Buka [konversi gambar](https://tools.muzanella.com/konversi-gambar).
2. Pilih file HEIC, PNG, atau WebP. Beberapa file sekaligus juga bisa.
3. Pilih format tujuan, lalu unduh.

Konversi dilakukan di browser Anda, sehingga foto tidak dikirim ke server.

## Memilih Format

| Format | Cocok untuk |
|---|---|
| JPG | Foto dan berkas pendaftaran. Diterima hampir di mana saja. |
| PNG | Logo, tangkapan layar, dan gambar dengan latar transparan. |
| WebP | Gambar untuk situs web. Lebih kecil, tetapi belum diterima semua formulir. |

Mengubah PNG transparan ke JPG akan mengisi bagian transparan dengan warna latar, karena JPG tidak mendukung transparansi.

## Supaya iPhone Langsung Memotret dalam JPG

Di iPhone, buka Pengaturan, Kamera, Format, lalu pilih "Paling Kompatibel". Foto berikutnya akan disimpan sebagai JPG. Foto lama tetap HEIC.

## Setelah Dikonversi

Kalau ukuran file masih terlalu besar untuk diunggah, lanjutkan dengan [cara mengompres foto](../cara-kompres-foto/cara-kompres-foto.md).
