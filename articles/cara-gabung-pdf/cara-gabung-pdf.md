# Cara Menggabungkan File PDF Tanpa Aplikasi dan Tanpa Upload

Pendaftaran kerja, beasiswa, atau CPNS sering meminta beberapa dokumen dalam satu file PDF: KTP, ijazah, transkrip, dan surat lamaran. Menggabungkannya bisa dilakukan langsung di browser.

## Langkah

1. Buka [gabung PDF](https://tools.muzanella.com/gabung-pdf).
2. Pilih semua file PDF yang ingin digabung.
3. Atur urutannya sesuai yang diminta panitia.
4. Klik gabungkan, lalu unduh hasilnya.

## Kenapa Tanpa Upload Lebih Aman

Dokumen pendaftaran berisi data pribadi seperti NIK, alamat, dan tanggal lahir. Di alat ini, file diproses di perangkat Anda sendiri dengan pustaka pdf-lib, sehingga tidak dikirim ke server mana pun. Cara ini juga lebih cepat untuk file besar karena tidak perlu menunggu proses upload.

## Tips

- Kalau ada dokumen berupa foto, ubah dulu menjadi PDF. Lihat [cara mengubah foto menjadi PDF](../cara-mengubah-foto-menjadi-pdf/cara-mengubah-foto-menjadi-pdf.md).
- Kalau hasilnya melebihi batas ukuran upload, kecilkan dengan [cara mengompres PDF](../cara-kompres-pdf/cara-kompres-pdf.md).
- Halaman yang miring atau tidak perlu bisa diperbaiki setelah digabung dengan [cara mengatur halaman PDF](../cara-atur-halaman-pdf/cara-atur-halaman-pdf.md).
- Beri nama file yang jelas, misalnya `Berkas_NamaLengkap_NomorPendaftaran.pdf`.

## Kalau PDF Terkunci

PDF yang diproteksi password biasanya tidak bisa digabung. Buka dulu dengan password-nya, simpan ulang tanpa proteksi, baru gabungkan.

## Referensi
